# CadImeLite v5 变更（2026-10-26 18:28）

这版在 v4 的代码基线上做了两处收紧，判定规则本身（绘图区→英文、前缀规则、类名表、LSP）没动。

## 1. 离开复位去抖

**问题证据**（ime-lite.log，2026-10-24）：

```
10:48:38.533 离开acad 复位=中文 窗口=0x10C4C conv 0x0001->0x0001 OK
10:48:39.964 cls=Chrome_WidgetWin_1 判据=绘图区(MDIClient) 目标=中 ...
10:48:40.357 离开acad 复位=中文 窗口=0x10C4C conv 0x0001->0x0001 OK
...
```

35 秒内刷了 5 次，`conv` 前后都是 `0x0001->0x0001`（值没变）。

**改法**（三条）：
1. 只有**工具确实把它设成过英文**（`_lastWant == 0`）才复位；
2. 复位前先读实际状态，已经是中文就跳过，**不写日志**；
3. 同一窗口 1 秒内不重复复位。

## 2. CEF 窗口不再算绘图区

**问题证据**：`10:48:37 cls=Chrome_WidgetWin_1 判据=绘图区(MDIClient)` —— MDI 区里嵌的 Chromium 窗口被当成绘图区强制切中文，进出反复触发。

**改法**：父链里出现 Chromium 系类名（`Chrome_WidgetWin` / `Chrome_RenderWidgetHostHWND` / `CefBrowserWindow` / `msedgewebview2`）就不算绘图区，回落到前缀规则和类名表；没规则就不动作。
