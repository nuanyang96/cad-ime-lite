# CAD 输入法助手 · 使用说明

## 这是什么

在 AutoCAD 里自动切换中/英文输入：

- 敲命令（`L`、`CO`、`TR`…）→ **自动英文**
- 双击多行文字 / 单行文字 → **自动中文**
- 退出文字编辑 → **自动回英文**
- 切到微信、浏览器 → **自动还你中文**

**只对 AutoCAD 生效**，其他软件一律不碰。

---

## 安装（就一步）

**双击 `CadImeLite.exe`** 就行。

它会自己做完这些事，你不需要懂：

| 它做什么 | 结果 |
|---|---|
| 复制自己到 `%LOCALAPPDATA%\CadImeLite\` | 桌面上的这个删了也不影响 |
| 写 `C:\CadImeSwitch\CadImeSwitch.lsp` | AutoCAD 靠它判断"是不是在编辑文字" |
| 登记进 AutoCAD 的「启动组」 | 打开 CAD 就自动加载，不用手动 APPLOAD |
| 加开机自启 | 以后开机自己跑 |
| 托盘出现「中 / 英」图标 | 装好了 |

> **装完请重启一次 AutoCAD**，让它加载刚登记的 LSP。

---

## 怎么验证装好了

1. 右下角托盘有 **「中」/「英」** 图标 → 程序在跑
2. 打开 AutoCAD，敲 `L` → 应该是**英文字母**
3. 双击一个多行文字进去 → 应该**能直接打中文**

三条都对就是正常。

---

## 如果不对

**图标不在？**
重新双击一次 `CadImeLite.exe`（它只允许跑一个，重复点不会出问题）。

**命令还是中文 / 多行文字还是英文？**
1. 先**重启 AutoCAD**（LSP 是开机时加载的）
2. 还不行就看日志：托盘右键 → **打开日志**
   - 找到 `自装：LSP 已登记到 AutoCAD 启动组` → LSP 这块没问题
   - 找到 `自装：未能登记启动组` → 说明装的时候 AutoCAD 从没运行过；先开一次 AutoCAD，再双击一次本程序

**日志在哪：** `%LOCALAPPDATA%\CadImeLite\ime-lite.log`

---

## 已知限制

| 限制 | 说明 |
|---|---|
| 微信输入法 / 搜狗拼音下，命令行按 `Shift` 没反应 | 程序是"关掉输入法"来表达英文，不是改模式；微软拼音不受影响 |
| 偶发一次没切过去 | 程序会自动重试，日志里能看到，最终结果正确 |
| 只认常见输入法 | 名单外的输入法会走保守策略，日志里能看出是"未识别" |

---

## 卸载

1. 托盘右键 → **退出**
2. 删掉目录 `%LOCALAPPDATA%\CadImeLite\`
3. 删掉目录 `C:\CadImeSwitch\`
4. 去掉两项自启：
   - 注册表 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` 里的 `CadImeLite`
   - AutoCAD 里：`APPLOAD` → 启动组 → 删掉 `CadImeSwitch.lsp`

> 不想删文件、只想暂时关掉：托盘右键 → **暂停**。

---

## 它不会做什么

- 不改你的图纸
- 不联网
- 不读你的数据
- 只处理 AutoCAD 窗口的输入法状态，其他程序完全不碰
